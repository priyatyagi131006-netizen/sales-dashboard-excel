# Sales Dashboard Project 📊

## Overview
This is an interactive sales dashboard created in Microsoft Excel to analyze sales performance across regions, products, and salespersons.

## Features
- Interactive slicers
- Monthly revenue trend analysis
- Region-wise revenue comparison
- Product-wise revenue analysis
- Salesperson performance tracking

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## Key Insights
- January recorded the highest revenue
- North region generated the highest sales revenue
- Laptop contributed the majority of total revenue
- Aman was the top-performing salesperson
